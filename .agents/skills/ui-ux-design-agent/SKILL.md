# UI/UX Design System Skill — KabaadLink Light Theme

Clean, professional, light-themed design inspired by modern fintech/marketplace apps.

---

## 🎨 1. Color System (Light Green Eco Theme)

- **Background:** `bg-gray-50` (light off-white) / `bg-white` (cards/panels)
- **Primary Green:** `#16A34A` (green-600) — buttons, icons, active states, links
- **Primary Green Hover:** `#15803D` (green-700) — hover states
- **Primary Green Light:** `#F0FDF4` (green-50) — light tint backgrounds, active nav items
- **Primary Green Border:** `#BBF7D0` (green-200) — subtle green borders
- **Text Primary:** `#111827` (gray-900) — headings, labels
- **Text Secondary:** `#6B7280` (gray-500) — descriptions, metadata
- **Text Muted:** `#9CA3AF` (gray-400) — timestamps, subtle info
- **Card Surface:** `bg-white` with `border border-gray-200 rounded-2xl shadow-sm`
- **Sidebar:** `bg-white` with `border-r border-gray-200`
- **Status Badges:**
  - `OPEN`: `bg-green-50 text-green-700 border border-green-200`
  - `CLAIMED`: `bg-amber-50 text-amber-700 border border-amber-200`
  - `PICKED_UP`: `bg-blue-50 text-blue-700 border border-blue-200`
  - `COMPLETED`: `bg-green-100 text-green-800 border border-green-300`
  - `CANCELLED`: `bg-red-50 text-red-700 border border-red-200`

## 🖋 2. Typography
- **Font:** `Inter` from Google Fonts (clean, professional sans-serif)
- **Headings:** `font-bold text-gray-900`
- **Body:** `text-gray-600 text-sm`
- **Labels:** `text-xs font-semibold text-gray-500 uppercase tracking-wider`

## ⚡ 3. Interaction Patterns
- **Card Hover:** `hover:shadow-md hover:border-green-200 transition-all duration-200`
- **Button Primary:** `bg-green-600 hover:bg-green-700 text-white font-semibold rounded-xl px-6 py-3 transition-colors`
- **Button Secondary:** `bg-white border border-gray-300 hover:border-green-400 text-gray-700 rounded-xl`
- **Inputs:** `bg-white border border-gray-300 rounded-xl px-4 py-3 focus:ring-2 focus:ring-green-500 focus:border-green-500`
